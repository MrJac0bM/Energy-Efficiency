# Energy Efficiency Pipeline

Pipeline modular en Python para analizar y predecir la eficiencia energética de edificios. Implementa EDA, transformación de datos y regresión lineal con descenso de gradiente desde cero.


## Instalación y Ejecución

1. Clonar el repositorio:
git clone https://github.com/MrJac0bM/Energy-Efficiency.git
cd Energy-Efficiency

2. Instalar dependencias:
- macOS / Linux: pip3 install pandas numpy matplotlib openpyxl
- Windows: pip install pandas numpy matplotlib openpyxl

3. Ejecutar el proyecto:
- macOS / Linux: python3 main.py
- Windows: python main.py

## Dataset

El dataset de Eficiencia Energética ya viene incluido en el repositorio, ubicado en data/raw/energy_efficiency.xlsx.
